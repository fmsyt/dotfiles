# WezTerm keybindings cheat sheet

キーバインドの定義は [`keybinds.lua`](./keybinds.lua) にある。

## 基本

- Leader は `Ctrl-f`（入力後 2 秒間有効）
- 以下の `Leader → x` は、`Ctrl-f` を離してから `x` を押す
- tmux 内でも同じキーを使える。WezTerm が `WEZTERM_IN_TMUX=1` を検出すると、対応するキーを tmux に転送する
- Zellij 内では、対応しているキーのみ Zellij に転送する

## ペイン

まずはここを覚える。

| キー | 動作 |
| --- | --- |
| `Leader → h` | 左のペインへ移動 |
| `Leader → j` | 下のペインへ移動 |
| `Leader → k` | 上のペインへ移動 |
| `Leader → l` | 右のペインへ移動 |
| `Leader → %` | 左右に分割 |
| `Leader → "` | 上下に分割 |
| `Leader → z` | 現在のペインをズーム／解除 |
| `Leader → x` | 現在のペインを閉じる（確認あり） |

### ペインサイズ

2 キー目の矢印を押すときに `Ctrl` を押しておく。1 回につき 5 セル変更する。

| キー | 動作 |
| --- | --- |
| `Leader → Ctrl-←` | 左方向へサイズ変更 |
| `Leader → Ctrl-↓` | 下方向へサイズ変更 |
| `Leader → Ctrl-↑` | 上方向へサイズ変更 |
| `Leader → Ctrl-→` | 右方向へサイズ変更 |

## タブ

| キー | WezTerm での動作 |
| --- | --- |
| `Leader → t` | 新しいタブ |
| `Leader → w` | 現在のタブを閉じる（確認あり） |
| `Leader → [` | 前のタブ |
| `Leader → ]` | 次のタブ |
| `Ctrl-Shift-Tab` | 前のタブ |
| `Ctrl-Tab` | 次のタブ |
| `Leader → {` | ペインを反時計回りに入れ替える |
| `Leader → }` | ペインを時計回りに入れ替える |

## ワークスペース

| キー | WezTerm での動作 |
| --- | --- |
| `Leader → s` | ワークスペース一覧を表示 |
| `Leader → $` | 現在のワークスペース名を変更 |
| `Leader → n` | 前のワークスペース |
| `Leader → p` | 次のワークスペース |

tmux 内では、これらのキーは tmux の同名キーへ転送されるため、動作の意味が異なる場合がある。

## その他

| キー | WezTerm での動作 |
| --- | --- |
| `Leader → =` | 背景の不透明度を上げる |
| `Leader → -` | 背景の不透明度を下げる |
| `Alt-Enter` | フルスクリーン切り替え |
| `Ctrl-R` / `Ctrl-Shift-R` | 設定を再読み込み |
| `Ctrl-Shift-V` / `Super-V` | クリップボードから貼り付け |
| `Leader → d` | WezTerm では何もしない。tmux／Zellij では detach を転送 |

## コピーモード

コピーモードに入った後は Vim に近い操作が使える。

| キー | 動作 |
| --- | --- |
| `h` / `j` / `k` / `l` | カーソル移動 |
| `w` / `b` / `e` | 単語単位で移動 |
| `0` / `^` / `$` | 行頭／最初の非空白／行末へ移動 |
| `g` / `G` | スクロールバックの先頭／末尾へ移動 |
| `v` | セル選択を開始 |
| `V` | 行選択を開始 |
| `Ctrl-v` | 矩形選択を開始 |
| `o` | 選択範囲の反対側へ移動 |
| `y` | コピーしてコピーモードを終了 |
| `q` / `Escape` / `Ctrl-c` | コピーモードを終了 |
| `Ctrl-u` / `Ctrl-d` | 半ページ上／下へ移動 |
| `Ctrl-b` / `Ctrl-f` | 1 ページ上／下へ移動 |
